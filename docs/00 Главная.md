# AI Life Planner — центр проекта

AI Life Planner — персональный AI-планировщик, который принимает свободный текст, запоминает контекст пользователя и превращает его в цели, задачи и реалистичный план дня.

> [!success] Текущий этап
> **Подготовка Today screen к dogfooding.** Технические препятствия для ежедневного использования сняты; следующий шаг — проверка продукта на реальных днях.

## Основной пользовательский цикл

```text
Выгрузить мысли → Получить план → Выполнить → Отметить → Адаптировать день
```

Подробнее: [[01 Продукт/Основной пользовательский сценарий]].

## Текущий статус разработки

- Telegram bot, FastAPI, PostgreSQL, SQLAlchemy и Alembic работают как единое MVP-ядро.
- Telegram и Web используют общий `process_user_message()` pipeline.
- Доступны mock, OpenAI-compatible и native Ollama parser providers с безопасным fallback.
- Today Web UI следует направлению Soft Light Daily Planner.
- Задачу можно перевести `planned → done` и вернуть `done → planned`.
- Изменение статуса защищено фильтрацией по `task_id + user_id`.
- Последняя dogfooding-подготовка: commit `a264dbb`, smoke-check прошёл, `pytest`: 39 passed, frontend build прошёл.

## Следующий контрольный результат

Провести минимум три последовательных дня реального использования, заполнить [[99 Шаблоны/Ежедневное тестирование|ежедневные записи]] и выделить одну повторяющуюся проблему, которая сильнее всего мешает основному циклу.
