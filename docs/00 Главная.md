# AI Life Planner — центр проекта

AI Life Planner — персональный AI-планировщик, который принимает свободный текст, запоминает контекст пользователя и превращает его в цели, задачи и реалистичный план дня.

> [!success] Текущий этап
> **iOS backend vertical slice.** Единственный основной клиент первого релиза — iOS. Android подключается после проверки iOS; Web и Telegram заморожены. FastAPI, PostgreSQL и Planning Engine являются единым product brain.

## Основной пользовательский цикл

```text
Выгрузить мысли → Получить план → Выполнить → Отметить → Адаптировать день
```

Подробнее: [[01 Продукт/Основной пользовательский сценарий]].

## Текущий статус разработки

- FastAPI, PostgreSQL, SQLAlchemy, Alembic и Planning Engine работают как единое ядро и source of truth.
- Mobile API v1 использует server-owned dogfood identity и не принимает произвольный user id.
- iOS, frozen Web/Telegram и будущий voice transcript сходятся в общий `process_user_message()` pipeline.
- Доступны mock, OpenAI-compatible и native Ollama parser providers с безопасным fallback.
- Frozen Today Web UI сохраняется только как compatibility surface.
- Задачу можно перевести `planned → done` и вернуть `done → planned`.
- Parser различает create/update/cancel/complete и fixed/flexible/unscheduled задачи.
- Backend ищет свободные интервалы, сохраняет валидные позиции и запрещает overlap.
- Conflict/clarification не оставляет частично применённых изменений.
- Неоднозначный ввод сначала создаёт persistent clarification; сильные изменения требуют confirmation с проверкой plan version.
- Message submit идемпотентен, а Web применяет один согласованный `DaySnapshot` без waterfall GET.
- Routine MVP поддерживает daily, weekdays и selected weekdays с идемпотентными occurrences.
- Изменение статуса защищено фильтрацией по `task_id + user_id`.
- Planning Engine v2 покрыт interval, integration и parser eval tests; актуальные результаты проверок фиксируются в commit report.

## Следующий контрольный результат

Нативный iOS Today реализован на основе [[07 Техническая документация/Mobile API Contract v1]] без дублирования parser, scheduler или planning logic. Следующий шаг — локальный dogfooding vertical slice на реальном iPhone.
