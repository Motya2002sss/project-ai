# Направление дизайна

Утверждённое направление: **Living Day / Intelligent Minimal**.

Предыдущее направление Soft Light Daily Planner отменено. Его бежево-зелёная палитра, карточная композиция задач и большой brain-dump блок больше не являются источником визуальной истины.

## Продуктовый принцип

> Результат впереди механики: пользователь сначала видит реалистично собранный день, а не инструменты обслуживания задач.

Today остаётся одной спокойной рабочей поверхностью. AI проявляется в фокусе и собранном плане, а не в декоративных эффектах, технических статусах или отдельном чате.

## Визуальная основа

- белый или холодный нейтральный canvas;
- графитовый основной текст;
- muted indigo как основной accent;
- restrained green только для подтверждённого выполнения;
- сильная типографическая иерархия;
- компактные task rows с мягкими separators вместо floating cards;
- минимум теней и декоративных контейнеров;
- один центрированный mobile-first canvas на desktop.

## Иерархия Today

1. Динамическая дата и доступ к работающим локальным настройкам.
2. Заголовок «Сегодня».
3. «Фокус дня» с коротким безопасным user-facing текстом.
4. Фактический progress `done / total`.
5. «Запланировано» только для задач с реальным временем.
6. «Без времени» для `not_scheduled` и задач дня без слота.
7. Фактический результат последнего изменения.
8. Вторичные данные только при наличии полезного содержимого.
9. Закреплённый natural-language composer.

## Контракты взаимодействия

- checkbox обратим и блокирует только текущую строку;
- ошибка статуса делает rollback и показывает inline «Повторить»;
- выполненная задача не прыгает в другое место во время feedback;
- draft composer не очищается до успешного ответа backend;
- processing не показывает выдуманные проценты или стадии;
- update summary содержит только изменения, подтверждённые API или сравнением данных;
- `focus_text` строится backend из реальных plan items и не использует raw LLM output;
- scheduled и unscheduled никогда не смешиваются и не получают выдуманное время.

## Состояния

Living Day проверяется не только в happy path. Обязательны:

- initial и partial loading;
- normal и mixed day;
- empty и all done;
- overloaded day;
- длинный русский текст;
- composer expanded, processing, success и error;
- checkbox pending, rollback и retry;
- backend unavailable;
- keyboard, reduced motion и масштабирование текста.

## Не использовать

- beige/sage как основную палитру;
- floating task cards;
- AI gradients, sparkle и декоративные orbs;
- неработающие microphone, edit, undo или navigation controls;
- fake task times, fake plan diff и fake processing stages;
- raw `intent`, JSON, parser fields, HTTP status или exception text;
- dashboard или desktop-grid как основную композицию Today.
