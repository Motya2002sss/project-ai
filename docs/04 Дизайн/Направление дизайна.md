# Направление дизайна

Утверждённое направление: **Soft Light Daily Planner**.

## Ощущение

Светлый, спокойный и воздушный личный планировщик, который хочется открыть утром. Интерфейс помогает начать день без ощущения контроля, вины или перегруженного task manager.

## Визуальная основа

- тёплый молочный фон;
- мягкие белые карточки;
- графитовый основной текст;
- спокойный серо-бежевый secondary text;
- sage green и приглушённые тёплые accents;
- минимум команд;
- touch-friendly mobile-first layout;
- радиус карточек до 8px в текущей системе.

## Иерархия Today

1. Сегодня, дата и спокойный фокус.
2. План на сегодня.
3. Progress внутри блока плана.
4. Задачи с обратимым checkbox.
5. Brain dump.
6. Спокойное AI-summary.
7. Вторичные блоки только при полезном содержимом.

## Поле свободного ввода

- заголовок: **Что у тебя в голове?**;
- подсказка: **Напиши как есть — я соберу из этого реалистичный план.**;
- основная кнопка: **Собрать день**.

## Состояния

- loading не меняет размеры основных блоков;
- error объясняет, что произошло, и сохраняет пользовательский ввод;
- empty day не выглядит ошибкой;
- done-задачи визуально спокойнее, но checkbox остаётся доступным;
- mixed state показывает реальный progress;
- all-done state позволяет выдохнуть, а не требует новых задач.

## Не использовать

- dashboard или desktop-grid как основную композицию;
- корпоративный синий;
- яркие AI-gradients и декоративные orbs;
- технические `intent` и `status` в основном интерфейсе;
- пустые секции ради симметрии;
- бесконечную визуальную полировку вместо проверки продуктовой ценности.
