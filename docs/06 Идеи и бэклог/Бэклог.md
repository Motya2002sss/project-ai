# Бэклог

Идея в этом списке не является обещанием или текущей задачей. Она поднимается в roadmap только после подтверждённой проблемы или отдельного решения.

## Возможности продукта

- [ ] Голосовой ввод: STT → `process_user_message()`.
- [ ] Android client после проверки iOS-версии.
- [ ] Week read model на семь дней.
- [ ] Reversible `PlanChange` и backend Undo.
- [ ] Быстрый перенос задачи на другой день.
- [ ] Редактирование задачи.
- [ ] Более глубокий вечерний итог и история прогресса.
- [ ] Goal progress history.
- [ ] PWA только после отдельного решения о разморозке Web.
- [ ] Telegram Mini App только после отдельного решения о разморозке Telegram.
- [ ] Простая production authentication.
- [ ] Personal beta.
- [ ] Markdown export дня.
- [ ] Экспорт дня в Obsidian.

## Технические улучшения перед production

- [ ] Production-safe deployment.
- [ ] Structured logging и monitoring.
- [ ] Rate limits.
- [ ] Usage analytics с минимизацией данных.
- [ ] Выбор production LLM provider.

## Не сейчас

- полноценный Obsidian plugin;
- двусторонняя синхронизация vault;
- развитие frozen Web/Telegram surfaces;
- сложный календарь;
- payments;
- enterprise roles;
- Kubernetes до появления реальной нагрузки.
