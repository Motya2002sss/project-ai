# Этапы проекта

## 1. Фундамент MVP — завершён

- FastAPI, PostgreSQL, SQLAlchemy и Alembic;
- Telegram bot;
- profile, goals, tasks и planning services;
- `Task.target_date` и today/tomorrow separation;
- smoke-check и базовые тесты.

## 2. Конвейер обработки естественного языка — завершён для MVP

- mock parser как обязательный fallback;
- OpenAI-compatible и native Ollama providers;
- Pydantic validation;
- parser eval dataset и strict eval;
- общий `process_user_message()` для Telegram и Web.

## 3. Веб-интерфейс Today — завершена подготовка Living Day к использованию

- mobile-first Living Day / Intelligent Minimal;
- закреплённый natural-language composer;
- безопасный day focus, plan и progress;
- scheduled и unscheduled task rows;
- reversible task checkbox;
- user-isolated status API;
- устойчивые loading/error/empty/mixed/overloaded/all-done states.

## 4. Тестирование на собственных сценариях — текущий этап

Цель: проверить основной пользовательский цикл на реальных днях и получить не список пожеланий, а наблюдаемые повторяющиеся проблемы.

Выход из этапа:

- минимум три последовательных ежедневных записи;
- определена одна главная UX или planning-проблема;
- принято решение о следующем продуктовом изменении.

## 5. Персональная бета — следующий крупный этап

- production authentication;
- безопасный deployment;
- несколько пользователей;
- monitoring и аналитика основных событий;
- production LLM provider.

## 6. Расширение продукта — позже

Voice, native app, calendar integration и другие крупные возможности рассматриваются после подтверждения ежедневной ценности Today-first сценария.
