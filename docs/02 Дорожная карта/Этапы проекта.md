# Этапы проекта

## 1. Фундамент MVP — завершён

- FastAPI, PostgreSQL, SQLAlchemy и Alembic;
- Telegram bot;
- profile, goals, tasks и planning services;
- `Task.target_date` и today/tomorrow separation;
- smoke-check и базовые тесты.

## 2. Конвейер обработки естественного языка — завершён для MVP

- mock parser как обязательный fallback;
- OpenAI-compatible и native Ollama providers;
- Pydantic validation;
- parser eval dataset и strict eval;
- общий `process_user_message()` для Telegram и Web.

## 3. Веб-интерфейс Today — завершена подготовка Living Day к использованию

- mobile-first Living Day / Intelligent Minimal;
- закреплённый natural-language composer;
- безопасный day focus, plan и progress;
- scheduled и unscheduled task rows;
- reversible task checkbox;
- user-isolated status API;
- устойчивые loading/error/empty/mixed/overloaded/all-done states.

Этот интерфейс заморожен после решения D-014 и остаётся compatibility surface.

## 4. Mobile API v1 — завершён backend P0

- server-owned local dogfood identity;
- Today snapshot с current/completed semantics;
- atomic capture и interaction responses;
- clarification/confirmation/conflict через общий pipeline;
- task status mutation с ownership, diff и snapshot.

## 5. Нативный iOS Today — текущий этап

Цель: реализовать первый основной клиент поверх Mobile API v1 без client-side planning logic и проверить основной пользовательский цикл на реальных днях.

Выход из этапа:

- нативный iOS Today проходит vertical slice;
- минимум три последовательных ежедневных записи на iOS;
- определена одна главная UX или planning-проблема;
- принято решение о следующем продуктовом изменении.

## 6. TestFlight beta — следующий крупный этап

- Sign in with Apple identity mapping;
- безопасный deployment;
- несколько пользователей;
- monitoring и аналитика основных событий;
- production LLM provider.

## 7. Android и расширение продукта — позже

Android подключается после проверки iOS-версии. Voice, Week, Path, general Undo, calendar integration и другие крупные возможности рассматриваются после подтверждения ежедневной ценности Today-first сценария.
