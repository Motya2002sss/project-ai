# Сейчас — далее — позже

## Сейчас — production candidate, локальная реализация

P0 Today dogfood slice сохранён, но текущая цель расширена до iOS-first production candidate по Mobile Product & Design Handoff. Работа выполняется последовательными contract slices; новые major features не добавляются вне зафиксированного scope.

### Реализовано локально

- [x] production runtime validation отделяет local/test от staging/production;
- [x] stable public user UUID, Apple identity mapping и one-use challenge;
- [x] hashed opaque access/refresh sessions, rotation, reuse detection, device logout и revoke-all;
- [x] authenticated `/api/v2/me`, собственный export и каскадное account deletion;
- [x] narrative onboarding preview/correction/apply, максимум три active goals и resource budget с 20% reserve по умолчанию;
- [x] mobile auth reducer, SecureStore credential pair, single-flight refresh и user-scoped cache/draft;
- [x] legacy Mobile API v1 и frozen Web/Telegram regression coverage.

### Текущий engineering slice

- [ ] goal/program/milestone/evidence domain;
- [ ] canonical progress и forecast без fake percentages;
- [ ] authenticated v2 Goal/Program/Progress API;
- [ ] v2 Today/capture/task mutations для production session.

### Известные release blockers

- [ ] Apple authorization-code exchange и credential revocation;
- [ ] real Sign in with Apple release build;
- [ ] staging database/config и restore drill;
- [ ] RevenueCat sandbox/Test Store lifecycle;
- [ ] production observability, AI budgets, feature kill switches и support tooling;
- [ ] TestFlight/App Store configuration and verification.

## Далее — complete iOS product journey

- Calendar Day/Week/Month и timezone-aware adaptive replanning;
- Apple Calendar read/import и подтверждаемая write sync;
- native welcome, Apple sign-in, onboarding и first-plan preview;
- full-day Today, Path и production Profile по утверждённой paper/burgundy системе;
- workout, nutrition и learning evidence flows;
- voice capture/transcription через тот же server pipeline;
- notifications/device registration;
- RevenueCat entitlements, paywall и restore purchases.

## После локальной реализации — operational verification

1. Отдельный staging без production user data.
2. PostgreSQL backup/restore drill и измерение recovery time.
3. Real Apple sandbox/release-signing checks.
4. RevenueCat monthly/annual/restore/expiration/grace/refund checks.
5. Owner dogfood, затем Internal TestFlight.
6. 5–10 invited users, затем 20–50 external testers.
7. App Store submission и staged public release только после acceptance gate.

## Статусы нельзя смешивать

Каждый отчёт отдельно указывает: locally implemented, staging verified, TestFlight verified, App Store configured, publicly released. Сейчас подтверждён только первый уровень для перечисленных completed slices.
