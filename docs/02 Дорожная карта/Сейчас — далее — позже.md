# Сейчас — далее — позже

## Сейчас — подготовка Today screen к dogfooding

Техническая часть спринта завершена в commit `a264dbb`:

- [x] обратимый checkbox `planned ↔ done`;
- [x] user isolation при смене статуса;
- [x] API-тесты `done`, `planned`, 404, 422 и legacy `/done`;
- [x] разделение большого frontend-файла на `api.ts`, `types.ts` и небольшие компоненты;
- [x] loading, error, empty, mixed и all-done states;
- [x] актуализация README;
- [x] `scripts/check_mvp.py`, `pytest` и frontend production build;
- [ ] минимум три последовательных дня реального dogfooding.

### Один текущий фокус

Использовать Today screen в реальной жизни и фиксировать, где продукт неправильно понимает пользователя, строит нереалистичный план или создаёт лишнюю ручную работу.

### Не сейчас

- native mobile app;
- voice;
- пользовательская интеграция с Obsidian;
- production auth;
- payments;
- сложный календарь;
- Kubernetes;
- бесконечная визуальная полировка.

## Далее — 3–7 дней ежедневного тестирования

- создавать запись через [[99 Шаблоны/Ежедневное тестирование]] каждый день;
- собирать реальные ошибки понимания;
- проверять реалистичность плана и корректность переносов;
- фиксировать повторяющиеся проблемы в [[05 Тестирование продукта/UX-проблемы]];
- выбрать одну следующую правку по частоте и влиянию на основной цикл.

## Позже — персональная бета

- простая production authentication;
- cloud deployment;
- production-safe logging и monitoring;
- usage analytics без сбора лишних персональных данных;
- несколько тестовых пользователей;
- выбор production LLM;
- расширение API и UI только под подтверждённые сценарии.
