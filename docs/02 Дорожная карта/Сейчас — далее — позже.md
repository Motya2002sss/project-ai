# Сейчас — далее — позже

## Сейчас — iOS Today vertical slice

FastAPI, PostgreSQL и Planning Engine становятся единственным product brain. Первый основной клиент — iOS; Web и Telegram заморожены.

- [x] authenticated Mobile API v1 без client-provided user id;
- [x] `GET /api/v1/today` с focus, progress, scheduled, unscheduled, completed и current item;
- [x] atomic capture response с `DaySnapshot` и factual `PlanDiff`;
- [x] отдельный mobile interaction response endpoint для clarification/confirmation/conflict;
- [x] task completion с ownership, diff и согласованным snapshot в одном ответе;
- [x] request idempotency для безопасного retry capture;
- [x] persistent clarification/confirmation/conflict context с expiry и user isolation;
- [x] deterministic availability, fixed conflict protection и minimal disruption;
- [x] frozen Web/Telegram остаются совместимыми и не удаляются;
- [x] утверждён [[04 Дизайн/Mobile Product & Design Handoff v1]]; экраны P1 зафиксированы визуально, но не расширяют текущий P0;
- [ ] нативный iOS Today client;
- [ ] локальный dogfooding iOS vertical slice.

### Один текущий фокус

Реализовать нативный iOS Today строго по [[07 Техническая документация/Mobile API Contract v1]] и проверить полный цикл: открыть Today → отправить изменение → уточнить/подтвердить → увидеть перестроенный день → отметить выполнение.

### Не сейчас

- Android;
- развитие Web или Telegram;
- voice;
- пользовательская интеграция с Obsidian;
- production auth;
- payments;
- сложный календарь;
- полноценный recurrence engine, исключения серий и calendar sync;
- отдельная бизнес-логика для voice;
- Kubernetes;
- бесконечная визуальная полировка.

## Далее — iOS local dogfooding

- провести 3–7 дней ежедневного тестирования на iOS;
- собирать реальные ошибки понимания;
- проверять реалистичность плана и корректность переносов;
- фиксировать повторяющиеся проблемы в [[05 Тестирование продукта/UX-проблемы]];
- выбрать одну следующую правку по частоте и влиянию на основной цикл.

## Позже — TestFlight и Android

- Sign in with Apple и multi-user auth identity mapping;
- TestFlight dogfooding;
- Android после проверки iOS-версии;
- cloud deployment;
- production-safe logging и monitoring;
- usage analytics без сбора лишних персональных данных;
- несколько тестовых пользователей;
- выбор production LLM;
- Week, Path, Profile, Voice и general Undo только под подтверждённые сценарии.
